#  Soundwave Music Production Website

Welcome to the Soundwave project—a sleek, responsive website built for musicians, producers, and sound engineers who want to learn from the best in the business. This site is designed to showcase an online music production program with style, clarity, and impact.

---

##  What This Is

This is more than just a landing page. It’s a digital front door to a creative community. Visitors can:

- Discover what Soundwave offers—from production to vocal recording
- See how the program delivers results (spoiler: +25% across the board!)
- Reach out directly via a clean, intuitive contact form
- Explore a modern, dark-themed design with red and white accents that pop

---

##  Mobile-Friendly & Responsive

We’ve made sure the site looks great on any device:

- When the screen width hits **480px or less**, the layout switches to a mobile-friendly version
- The content is **centered and capped at 1000px** for readability on larger screens
- It’s all about keeping things clean, accessible, and visually sharp

---

##  Interaction Details

We’ve added subtle but meaningful touches to make the site feel alive:

- **Links** change color on hover/active: `#FF6565`
- **Buttons** fade slightly on hover/active: `opacity: 0.9`

These micro-interactions help guide users and make the experience feel polished.

---

##  Tech Stack

Built with:

- **HTML5** for structure
- **CSS3** for layout and styling (including Flexbox, Grid, and media queries)
- **JavaScript** for interactivity and form handling
