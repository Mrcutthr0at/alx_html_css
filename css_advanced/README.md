# SmileSchool Landing Page

A vibrant, accessible, and responsive landing page for SmileSchool — a fictional platform teaching the art of smiling through engaging tutorials and expert-led content.

## Design Reference
This project follows the [SmileSchool Figma design](https://www.figma.com/design/4X0lrj93WGSBkcy0PInBxh/Homepage--Copy-?node-id=0-1&t=ZE4yMg8fuHtq0h7a-1) — duplicated to drafts for full access.

## Tech Stack
- HTML5 (semantic structure)
- CSS3 (custom styling, Flexbox layout)
- Font Awesome (iconography)
